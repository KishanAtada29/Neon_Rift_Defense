# Asteroid Rift Defense

## Project Description
Asteroid Rift Defense is a customized version of the Alien Invasion starter project.  
The original alien theme was changed into an asteroid defense theme. The player controls a custom spaceship, fires custom laser bullets, and defends against moving asteroids.

## Track
Track 2 - Custom Assets

## Custom Assets Added
- Custom space background
- Custom player spaceship
- Custom laser bullet image
- Custom asteroid image
- Custom sound effects and background music
